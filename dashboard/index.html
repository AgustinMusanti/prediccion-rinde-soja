Noroeste bonaerense · 5 partidos

Conocé cómo puede venir la campaña de soja, desde noviembre.

Cada mes, de noviembre a marzo, una estimación del rinde de soja para los cinco partidos del noroeste bonaerense y para toda la zona. Una referencia temprana para anticipar necesidades de acopio, logística y comercialización.

Estimación regional: es el rinde promedio de cada partido, no el de un lote individual.
